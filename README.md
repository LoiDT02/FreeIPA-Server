# 📘 Hướng dẫn sử dụng script cấu hình FreeIPA Server

## 1. Tạo file `.env`

Tạo file `.env` trong cùng thư mục với script `.sh`

---

## 2. Cấp quyền thực thi cho file `.sh`

Chạy lệnh sau để cấp quyền thực thi:

```bash
chmod +x install_freeipa.sh
```

---

## 3. Thực thi script

Sau khi tạo `.env` và cấp quyền xong,  có thể chạy script bằng lệnh:

```bash
./install_freeipa.sh
```
